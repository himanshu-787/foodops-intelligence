1. Functional Requirements (FR): System kya karega. Features.

ID	 Requirement
FR1	 User register aur login kar sakta hai
FR2	 User restaurants search aur filter kar sakta hai
FR3	 User cart mein items add kar sakta hai
FR4	 User order place kar sakta hai
FR5	 User order ka status dekh sakta hai
FR6	 Restaurant incoming order accept ya reject kar sakta hai


2. Non-Functional Requirements (NFR): System kaisa behave karega. Quality.

ID	Requirement	Category
NFR1	Restaurant list 500 ms ke andar load ho	Performance
NFR2	System 1,000 concurrent users handle kare	Scalability
NFR3	App 99.9% time available rahe	Reliability
NFR4	Passwords hashed store hon	Security
NFR5	Naya developer 1 din mein setup kar sake	Maintainability
